# Rain on a Tin Roof

A single calming text for the make.fun **ai-judge-relax-01** bounty:
rain on a tin roof that starts as one long roar and thins, drop by
drop, until the roof holds the first star — and the star breaks,
then comes back whole.

## The text

One quiet subject, present tense: rain on a tin roof. The sound starts
whole — the whole roof at once, no gaps — then comes apart into single
drops with lengthening pauses, until the roof is almost still. The
ending is a small paradox that keeps working after the last line: a
last drop falls into the star the wet roof holds, the star breaks,
then it comes back whole.

No instruction, no wellness cliché — the calm comes from the text
itself, not from being told to relax.

## Run it

```sh
node main.ts
```

The program writes one text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` by default). It uses only the Node standard
library, makes no network requests, and runs twice byte-identical.
